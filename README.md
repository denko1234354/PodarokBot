# Бот-поздравитель

Telegram-бот с меню «Поздравление», «Видео», «Стишок» и админ-панелью. Администратор может менять текст главного меню, поздравление, стишок и видео (ссылку или Telegram `file_id`). Настройки хранятся в SQLite и остаются после перезапуска.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. Узнайте свой Telegram ID, скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` и `ADMIN_ID`.
3. Установите зависимости и запустите бота:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python main.py
   ```

4. Напишите боту `/start`. Администратору также доступна команда `/admin`.

В редакторе видео отправьте HTTPS-ссылку на видео, Telegram `file_id` или дефис (`-`), чтобы удалить текущее видео. Видео по ссылке должно быть доступно Telegram Bot API для загрузки.
